# Content rating (IARC questionnaire)

**Play Console → Policy → App content → Content ratings.**

The rating is issued by the IARC bodies from your answers, not by Google.
Answering it dishonestly is the fastest route to a suspended app, and there is
nothing here worth shading: Hisn is a text-and-audio reference app with no
user-generated content that anyone else can see.

## The questionnaire

Every content question is **No**. Answer them individually rather than trusting
this table — the wording changes from time to time — but expect all of:

| Section | Answer |
| --- | --- |
| Violence — realistic, cartoon, or otherwise | No |
| Sexuality, nudity, suggestive content | No |
| Language — profanity, crude humour | No |
| Controlled substances — drugs, alcohol, tobacco | No |
| Gambling — real or simulated | No |
| Horror, fear, or disturbing imagery | No |
| Crime, discrimination, or extremism | No |

## Expected outcome

All-No answers on a reference app rate **ESRB Everyone / PEGI 3 / USK 0 / IARC
3+**, with no interactive-elements labels beyond, at most, "Digital Purchases:
No". If the questionnaire returns something higher, you mis-clicked — go back
rather than accepting it.

## After it is issued

- The rating applies **per release**. It does not need redoing for ordinary
  updates, but it does if the app gains user interaction, purchases, or ads —
  which for Hisn would mean the Tanzil licence had been dealt with first.
- Play shows the rating on the listing per territory. Some territories apply
  their own body's label; that is normal and needs no action.
