# Albanian localization provenance

Albanian is registered as `sq`, with the native name **Shqip**. It uses the
existing Latin UI font and a left-to-right layout. Catalog, content, and native
data generation follow `LOCALIZATION.md`.

`lib/i18n/sq.i18n.json` contains the project's Albanian interface translation.
`assets/data/categories.sq.json` and `assets/data/tasbih.sq.json` contain Albanian
category descriptions and tasbih meanings. These are project-authored wording,
not transcriptions of a published Albanian edition.

`assets/data/duas.sq.json` is generated by `tool/gen_sq_dua_overlay.py` from the
bundled Arabic/English content. Hadith meanings, titles, virtues and practical
instructions are **original project Albanian drafts**. They require qualified
Albanian language and religious review before release. Coverage and layout
tests establish technical completeness, not scholarly or linguistic approval.
The About screen identifies project draft meanings as awaiting qualified review.

Original Arabic recitations, repeat counts, IDs and hadith reference numbers
remain unchanged. Translated reference labels preserve the original identifiers
and existing grading/dispute notes. This work does not independently authenticate
the narrations or resolve disputed gradings.

Quran meanings are the published **Hasan Efendi Nahi** translation, edition
`sq.nahi`, obtained from [Tanzil](https://tanzil.net/trans/sq.nahi). The generator
checks every surah and verse against the app's index: 114 surahs and 6,236 verses.
Attribution is stored in the editions manifest and appears in About and on
shared Quran passages. Tanzil's [non-commercial terms](https://tanzil.net/trans/)
continue to apply.

Quran passages inside dua cards use the same translator's exact wording:

- Ayat al-Kursi: 2:255.
- The last three surahs: their complete verses, preceded by 1:1 for the basmalah.
- The waking passage: all eleven verses of 3:190–200, with verse numbers.
- Quran supplications: exact suffix excerpts from the relevant verse.
- Travel and calamity supplications: exact Quran excerpts alongside the
  separately identified project-authored hadith wording.

No published Albanian Hisn al-Muslim prose was copied or attributed to Nahi.
His credit applies to the Quran portions only. The `_meta` object records the
same distinction and a fingerprint of the base content. Generation refuses a changed base
until its Albanian translations have been reviewed and the expected fingerprint
is explicitly updated. Quran-containing dua references also carry Nahi’s credit,
including when exported as a dua rather than as a Quran verse.

Regenerate after source updates:

```powershell
python -X utf8 tool/gen_quran_translations.py
python -X utf8 tool/gen_sq_dua_overlay.py
dart run slang
dart run tool/sync_native_localizations.dart
dart run tool/validate_localizations.dart
python -X utf8 -m unittest discover -s test -p albanian_generator_test.py
flutter test --no-pub
```
